# Overview

**Cerberus CC Pro** is a professional command-line toolkit built for **payment security research, BIN analysis, validation testing, and educational demonstrations**.

The application provides utilities for analyzing Bank Identification Numbers (BINs), validating card numbers using the Luhn algorithm, generating test card numbers from BIN patterns, and simulating payment gateway validation workflows in controlled testing environments.

Its modern terminal interface, high-performance processing, and modular architecture make it suitable for developers, QA teams, and cybersecurity professionals working with payment systems.

# Features

## 🔍 BIN Analysis
- Analyze BIN/IIN patterns
- Detect issuing bank information
- Identify card brand
- Determine card level and type
- Country identification

# Installation

Clone the repository:

```bash
git clone https://github.com/CerberusMrX/Cerberus-CC.git
```

Navigate to the project directory:

```bash
cd Cerberus-CC-Pro
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python3 cerberus_cc.py
```

---

# Requirements

- Python 3.10+
- pip
- Linux, Windows, or macOS
